D2. Debug the Code

Find the bug, explain it in one sentence and write the corrected code.

Bug 1. The message always says adult.

let age = 15;
if (age = 18) { console.log("adult"); }

    Ans:We used = instead of ===. The = operator assigns a value, but === checks whether two values are equal. 

    let age = 15;
    if(age === 18){
        console.log("adult");
    }

Bug 2. The program stops with an error.
const total = 0;
for (let i = 1; i <= 3; i++) { total += i; }

    Ans : We declared total using const, but we are trying to change its value inside the loop. So, we should use let instead.

        let total=0;
        for(let i=1;i<=3;i++){
            total += i;
        }
        console.log("Total" , total);


Bug 3. Adding 5 gives a strange answer.

let age = prompt("Your age?"); // user types 20
console.log(age + 5);

       Ans:The prompt() function takes input as a string. So, we need to convert it into a number using Number() before adding 5.

       Corrected code:

            let age=Number(prompt("Your age?"));
            console.log(age + 5);

Bug 4. The loop prints nothing useful and then an error.
for (let i = 1; i <= 3; i++);
{ console.log(i); }

          Ans: There is an extra semicolon after the for loop, so the loop ends without executing the code inside the block. We need to remove it.

          Corrected code:

          for (let i = 1; i <= 3; i++)
          { console.log(i); }

Bug 5. The browser tab freezes.
let n = 5;
while (n > 0) { console.log(n); }

         Ans: We forgot to decrease the value of n inside the loop. So, the condition is always true, and the loop keeps running. We should use n-- instead of n++.

         Corrected code:
   
           let n = 5;
           while (n > 0)
         { console.log(n);
           n++; }              

Bug 6. Tuesday is printed together with Monday.
let day = 1;
switch (day) {
case 1: console.log("Monday");
case 2: console.log("Tuesday");
}

        Ans:We forgot to use break after each case. So, the switch continues to the next case even after finding a match.

        Corrected code:
      
       let day = 1;
       switch (day) {
       case 1: console.log("Monday");
       break;
       case 2: console.log("Tuesday");
          break;
       default:console.log("weekdays");
      }
