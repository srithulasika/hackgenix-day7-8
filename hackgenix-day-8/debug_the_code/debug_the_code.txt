D2. Debug the Code

Find the bug, explain it in one sentence and write the corrected code.


Bug 1. The result is NaN.

function add(a, b) { console.log(a + b); }
let r = add(1, 2);
console.log(r + 1);

Explanation: The function only prints the result but does not return it. So, 'r' becomes undefined and 'r + 1' gives NaN.

Corrected code:

function add(a, b) {
    return a + b;
}
let r = add(1, 2);
console.log(r + 1);


Bug 2. It prints the function instead of the text.


const greet = () => "Hi";
console.log(greet);

Explanation: We are only referring to the function. We need to use '()' to call and execute the function.

Corrected code:

const greet = () => "Hi";
console.log(greet());

Bug 3. The numbers are not in the right order.

const nums = [10, 9, 1, 100];
nums.sort();
console.log(nums);

Explanation: By default, sort() compares numbers as strings. We need to use a compare function to sort numbers in the correct order.

Corrected code:

const nums = [10, 9, 1, 100];
nums.sort((a, b) => a - b);
console.log(nums);

Bug 4. An error appears for an empty list.

const prices = [];
const total = prices.reduce((s, p) => s + p);

Explanation: The array is empty, so reduce() has no first value to use as the accumulator. We need to give an initial value of 0.

Corrected code:

const prices = [];
const total = prices.reduce((s, p) => s + p, 0);
console.log(total);

Bug 5. The value is undefined.

const student = { name: "Asha" };
console.log(student.Name);

Explanation: JavaScript is case-sensitive. The property name is 'name', but we used 'Name'.

Corrected code:

const student = { name: "Asha" };
console.log(student.name);

Bug 6. The parsing fails.

const data = JSON.parse("{'name': 'Asha'}");

Explanation: JSON requires double quotes around property names and string values. Here, we used single quotes, so the parsing fails.

Corrected code:

const data = JSON.parse('{"name":"Asha"}');

Bug 7. The original list is changed too.

const original = [1, 2, 3];
const copy = original;
copy.push(4);
console.log(original);

Explanation: Both variables refer to the same array. So, changing the copy also affects the original. We can use the spread operator to create a separate array.

Corrected code:

const original = [1, 2, 3];
const copy = [...original];
copy.push(4);
console.log(original);

Bug 8. The name is undefined.

const person = { name: "Ravi", show: () => console.log(this.name) };

Explanation: Arrow functions do not have their own 'this'. So, we need to use a regular method to access the object's name.

Corrected code:

const person = {
    name: "Ravi",
    show() {
        console.log(this.name);
    }
};
person.show();
